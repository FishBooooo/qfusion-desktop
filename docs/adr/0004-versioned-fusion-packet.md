# ADR-0004：版本化 Fusion Packet

- 状态：Accepted
- 日期：2026-07-27

## 背景

融合模型需要三套模型的结构化结果，但直接读取自由文本或内部对象会造成字段漂移、周期错配、提示注入和模型耦合。

## 决策

每套模型完整结果先经 Pydantic 和 JSON Schema 验证，再投影为版本化的最小 Fusion Packet。融合入口验证：

- 契约版本受支持；
- 模型类型各不相同且恰好一份；
- `snapshot_id`、目标永久标识和市场一致；
- 周期可对齐；
- 校准置信度、数据质量、风险摘要和证据引用完整；
- 所有证据引用存在于该快照。

融合模型不以自由文本报告作为主要输入。任何验证失败都停止融合并产生可审计错误，不能猜测或填补关键字段。

## 后果

契约版本升级需要兼容策略和测试，但能降低耦合、阻止错配并稳定复现。融合之后仍必须经过独立风险引擎。
