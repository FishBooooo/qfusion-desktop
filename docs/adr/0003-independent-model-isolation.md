# ADR-0003：独立模型隔离边界

- 状态：Accepted
- 日期：2026-07-27

## 背景

华尔街、量化和游资模型必须基于同一数据快照独立形成结论。如果共享结果 Repository、进程全局变量或宽泛数据库访问，模型可能发生无意信息泄漏，破坏独立性。

## 决策

模型编排器为三套模型创建独立运行上下文。每个上下文只获得：

- 同一 `snapshot_id` 的只读、能力受限 Snapshot Reader；
- 本模型的配置和版本；
- 本模型命名空间的 Result Writer；
- 受限的审计与指标接口。

独立模型不获得其他结果 Repository、Fusion Repository 或账户下单能力。正式实现优先使用独立 worker 进程和序列化输入契约；即使采用进程内测试替身，也必须保持相同接口和导入边界。

## 验证

后续测试至少覆盖：

- 三次运行的 `snapshot_id` 完全一致；
- 任一模型请求其他模型结果时被拒绝；
- 调度顺序变化不改变模型可见输入；
- Fusion 只在三份已验证结果完成后运行；
- 失败模型不会被旧结果悄悄替代。

## 后果

隔离增加序列化和编排成本，但使独立性可测试、可审计。共享特征只能通过版本化快照提供，不能通过模型间调用共享结论。
