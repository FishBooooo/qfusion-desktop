# ADR-0005：缓存优先的 LLM 策略

- 状态：Accepted
- 日期：2026-07-27

## 背景

平台必须在无云模型、无本地模型甚至断网时运行，并把 Token 成本和敏感文本外发降到最低。LLM 也不适合作为关键数值或风险判断器。

## 决策

系统支持 `off`、`local`、`hybrid`、`cloud` 四种模式，并默认缓存优先。调用键至少包含：

```text
sha256(source_content + extraction_prompt_version + model_version)
```

只发送新增或变化的必要上下文，要求结构化 JSON 输出并经 Pydantic 验证。验证重试次数有限，失败后使用确定性模板降级。

每次调用记录任务、模型、输入/输出 Token、费用估算、缓存命中和内容哈希。实施每日和每月硬预算，超限后停止云调用。CI 永远使用 Mock LLM。

LLM 不计算指标、收益、交易成本、仓位、时间有效性、回测结果或风险许可，也不能提交订单。

## 后果

需要维护缓存版本、失效策略和 Token 账本，但可以实现离线核心能力、可预测成本和可审计调用。
